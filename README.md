# 📚 Library Management System

A simple **Library Management System** made using **Python**.
This is a beginner-level project created to practice Python programming concepts.

## 📝 About the Project

This program helps manage books and students in a library. It has separate options for **Admin** and **Student** users.

The program stores book information, student records, and issued-book details using Python dictionaries and lists.

## ✨ Features

### 👨‍💼 Admin

* Admin Login
* Add a new book
* Issue a book
* Return a book
* Remove a book
* Search for books
* Display all books
* View issued books
* View student records

### 👨‍🎓 Student

* Student Login
* Search for books
* View available books
* View issued books
* Return a book
* Logout

## 🛠️ Technologies Used

* Python 3
* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements
* Input Validation

## ▶️ How to Run

### 1. Install Python

Make sure **Python 3** is installed on your computer.

### 2. Download or Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 3. Open the Project Folder

```bash
cd Library-Management-System
```

### 4. Run the Program

```bash
python library_management.py
```
